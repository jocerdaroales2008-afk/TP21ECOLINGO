## Supabase

Configura `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY` para habilitar el envío de sugerencias. Crea la tabla una vez en el SQL editor:

```sql
create table public.community_suggestions (
	id bigint generated by default as identity primary key,
	name text not null,
	address text not null,
	latitude double precision,
	longitude double precision,
	materials text[] not null default '{}',
	status text not null default 'pending',
	created_at timestamptz not null default now()
);

alter table public.community_suggestions enable row level security;
create policy "Anyone can submit suggestions"
	on public.community_suggestions for insert
	with check (status = 'pending');
```

Para cargar los puntos oficiales del MMA y mostrarlos en el mapa, crea también esta tabla:

```sql
create table public.recycling_points (
	 id bigint generated by default as identity primary key,
	 name text not null,
	 address text not null,
	 commune text not null default 'Chile',
	 region text not null default 'Chile',
	 latitude double precision not null,
	 longitude double precision not null,
	 accepted_materials text[] not null default '{}',
	 hours text,
	 created_at timestamptz not null default now(),
	 unique (latitude, longitude)
);

alter table public.recycling_points enable row level security;
create policy "Anyone can read official recycling points"
	on public.recycling_points for select using (true);

grant usage on schema public to service_role;
grant select, insert, update, delete on public.recycling_points to service_role;
```

El seed usa la clave privada `SUPABASE_SERVICE_ROLE_KEY`, por lo que debe ejecutarse solo desde una terminal local o servidor seguro. Copia `.env.example` a `.env`, completa `SUPABASE_URL` y `SUPABASE_SERVICE_ROLE_KEY`, y ejecuta:

```bash
npm run seed:mma
```

La app usa las variables `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY` para leer esos puntos. Al pulsar **Usar mi ubicación actual**, el navegador mantiene un seguimiento GPS activo, recalcula las distancias y actualiza el marcador; **Cómo llegar** abre la ruta en Google Maps.
